Object-Based Programming

A searchable, handout-aligned guide to objects, references, methods, scope, conversions, and comparison.

Learning objectives & overview

Explain classes and objects; create library objects; call instance and static methods; explain String immutability and use StringBuilder; pass arguments; identify variable scope; cast and convert primitives, wrappers, and text; compare objects and find their runtime type. Unit 5 builds on familiar String and Scanner objects; Unit 6 introduces designing your own classes.

1. Classes and Objects

Class: a blueprint describing data and actions (methods); by itself it is only a description.
Object / instance: a specific thing created from a class, with its own data. A class can create many instances.

1.1 Java Class Library (API)

The API is Java's collection of ready-made classes grouped into packages. java.lang is available automatically; other packages need imports.

1.2 Creating objects with new

Syntax: ClassName variable = new ClassName(startingData);. Parentheses hold initial data. The dot operator calls an object's methods.

String school = new String("ISAT-U");
StringBuilder message = new StringBuilder("Welcome");
String city = "Iloilo"; // String literal shortcut
message.append(" to "); message.append(school);
System.out.println(message); // Welcome to ISAT-U
System.out.println(city.toUpperCase()); // ILOILO
String shortcut: literals create Strings directly; new String(...) is rarely needed. StringBuilder and Scanner use new.

1.3 Objects are reference types

Object variables hold a reference (an arrow to the object), not the object itself. Assignment copies the arrow, not the object.

StringBuilder sb1 = new StringBuilder("Hello");
StringBuilder sb2 = sb1; // same object
sb2.append(" World");
System.out.println(sb1); // Hello World
System.out.println(sb2); // Hello World
StringBuilder sb3 = null;
System.out.println(sb3); // null
null means no object. Calling sb3.append("x") throws NullPointerException.

2. Methods

A method is a named block that performs a task; it can receive parameters and return a result.

2.1 String instance methods

Call an instance method on an object. Indexes start at zero; substring start is included and end excluded.

MethodPurpose and example
length()Count; "Java".length() → 4
toUpperCase()Copy in capitals; "Java" → "JAVA"
toLowerCase()Copy in lowercase; "Java" → "java"

String school="ISAT-U Iloilo";
System.out.println(school.length());       // 13
System.out.println(school.toUpperCase());  // ISAT-U ILOILO
System.out.println(school.charAt(0));      // I
System.out.println(school.contains("Iloilo")); // true
System.out.println(school.indexOf("Iloilo"));  // 7
System.out.println(school.substring(0,6)); // ISAT-U

2.2 String vs StringBuilder

String is immutable: methods return a new value. Save it. StringBuilder mutates its object.

String name="ana"; name.toUpperCase(); // lost; still ana
name=name.toUpperCase();             // now ANA
StringBuilder sb=new StringBuilder("Ana");
sb.append(" Cruz"); sb.insert(0,"Ms. "); // Ms. Ana Cruz
sb.reverse(); // zurC anA .sM
Builder methodEffect
append(x)Add to end

reverse()Reverse characters

2.3 Writing methods

static returnType methodName(parameterList) {
  // statements
  return value; // omit for void
}

Header parts: static class-level modifier; return type or void; method name; typed parameter list; body in braces. Return ends a method and sends a result. A parameter is in the header; an argument is the actual call value.

static void greet(String name) { System.out.println("Hello, "+name); }
static int square(int n) { return n*n; }
static double average(int a,int b,int c) { return (a+b+c)/3.0; }
greet("Ana"); int sq=square(7); // argument Ana; sq = 49
Arguments match parameters by number, order, and type. Every non-void path returns the declared type. A void call cannot be assigned to a variable.

2.4 Passing arguments

Java always passes by value. A primitive parameter gets a copy of the primitive; changing it doesn't change the caller. An object/array parameter gets a copy of its reference, so mutation of the shared object is visible. Reassigning the parameter doesn't reassign the caller's reference.

static void tryChange(int n){ n=100; }
static void bonus(int[] a){ for(int i=0;i<a.length;i++) a[i]+=5; }
int num=5; tryChange(num); // remains 5
int[] scores={80,90,70}; bonus(scores);
System.out.println(Arrays.toString(scores)); // [85, 95, 75]
The handout informally calls the object case pass-by-reference; technically Java passes the reference value by value.

4. Variable scope

Scope is where a variable is usable. Blocks are between { }. Nested blocks see enclosing variables; enclosing code cannot see nested declarations.

static int total=0; // class variable
public static void main(String[] args) {
  int x=10; // local
  for(int i=1;i<=3;i++){ int doubled=i*2; total+=doubled; }
  addBonus(5);
}
static void addBonus(int bonus){ total+=bonus; } // parameter
// total is 17; i ends with the loop
KindDeclaredScope
LocalMethodFrom declaration to block end
ParameterMethod headerMethod body
Loop variableFor statementThat loop only
Class variableClass, with staticAll class methods; shared
Instance variableClass, without staticInstance methods; per object
Out-of-scope use: cannot find symbol. Duplicate name in overlapping scope: variable is already defined. Separate methods can each declare x.

5. Casting and converting

Casting changes a value's type, e.g. (int)9.7.

5.1 Primitive casting

Widening is automatic: byte → short → int → long → float → double; char → int converts Unicode. Narrowing needs explicit cast and may lose information.

int count=7; double wide=count; // 7.0
double price=99.75; int pesos=(int)price; // 99, truncates
char letter='A'; int code=letter; // 65
char next=(char)(code+1); // B
double average=(double)17/5; // 3.4

Narrowing truncates, not rounds; use Math.round to round. Cast before division to retain decimals.

5.2 Primitive, wrapper, text

PrimitiveWrapperText → value
intIntegerInteger.parseInt("19")
doubleDoubleDouble.parseDouble("1.75")
longLongLong.parseLong("9000000000")

Number → text: String.valueOf(value). Autoboxing converts primitive to wrapper; unboxing reverses it.

int age=Integer.parseInt("19");
double gpa=Double.parseDouble("1.75");
String text=String.valueOf(age);
Integer boxed=age; int unboxed=boxed;
Invalid number text such as Integer.parseInt("abc") throws NumberFormatException.

5.3 Read numbers as text

Scanner sc=new Scanner(System.in);
System.out.println("Enter quantity:");
String line=sc.nextLine();
int qty=Integer.parseInt(line.trim());
System.out.println("Total cost: "+qty*25+" pesos");

5.4 Object casting preview

Upcasting to Object is automatic; downcasting to the real class is explicit.

Object item="Hello"; // upcast
String text=(String)item; // downcast
System.out.println(text.toUpperCase()); // HELLO

Wrong downcast throws ClassCastException; use instanceof first.

6. Comparing Objects and checking types

6.1 == vs equals()

For object references, == means same object. equals() compares content as that class defines it.

String a="java", b=new String("java"), c=a;
a==b; // false
a.equals(b); // true
a==c; // true
"JAVA".equalsIgnoreCase(a); // true

String literal pooling can make == seem to work; don't rely on it. Compare text with equals or equalsIgnoreCase.

6.2 equals() pitfalls

StringBuilder.equals behaves like identity comparison. Compare a.toString().equals(b.toString()). Integer wrappers should also use equals; caching −128 to 127 can make == misleading.

StringBuilder a=new StringBuilder("hi"), b=new StringBuilder("hi");
a.equals(b); // false
a.toString().equals(b.toString()); // true
Integer x=1000,y=1000;
x==y; // don't rely on it
x.equals(y); // true

6.3 Find an object's class

Object a="hello", b=42, c=new StringBuilder("hi");
a.getClass().getName(); // java.lang.String
b.getClass().getName(); // java.lang.Integer
c.getClass().getName(); // java.lang.StringBuilder
a instanceof String; // true
b instanceof String; // false

Use instanceof before a downcast to check runtime compatibility.

Key takeaways

  • Class is blueprint; object is instance; API supplies ready-made classes.
  • new creates; dot accesses. Reference assignment shares the object.
  • String is immutable; store results. StringBuilder changes in place.
  • Java passes copies: primitive values or object references.
  • Instance members need objects; static members use class names. Scope ends at block.
  • Widening is automatic; narrowing needs cast. Wrappers parse text.
  • Compare content with equals; inspect types with getClass or instanceof.
